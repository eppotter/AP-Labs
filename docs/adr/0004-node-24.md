# ADR 0004: Move from Node 20 to Node 24 (LTS)

- Status: accepted
- Date: 2026-10-24
- Decided by: the Orchestrator (decide and report), reported to Ely in Slack
- Supersedes: the Node 20 choice in ADR 0001 and ADR 0002

## Context

Story 6.1 added Slack Bolt 5.1.0. Its Socket Mode client (`@slack/socket-mode` 3.1.0) depends on `undici` 8, which requires Node 22.19 or newer. CI ran Node 20, and the build failed there while passing locally on a newer Node.

Node 20 reached end of life in April 2026. It no longer receives security fixes.

## Decision

The template targets **Node 24**, the current long-term-support line:

- `package.json` `engines`: `>=24`
- CI `node-version: 24`
- `.nvmrc`: `24`

Client forks inherit this.

## Consequences

- The Slack libraries run on their supported runtime, so there is no need to pin old versions around an end-of-life Node.
- Forks get a supported runtime for two more years. Node 24 stays in maintenance until April 2028.
- Builders and reviewers on newer local Node versions still match CI closely. Node-only features newer than 24 must not be used.
