## What the numbers don't show

1. **An engine test read a Brightside path and broke clean-bones (#141).**
   - A unit test asserted that `win-back.sql` and `unpaid-invoices.sql` existed. CI's clean-bones job deletes the example, so the test failed there.
   - The fix moved that check under `examples/brightside/test/`.
   - The rule was already in AGENTS.md. Briefs now repeat it, and builders simulate clean-bones before they report.
2. **A CI change couldn't be pushed (11.2).**
   - The stored GitHub token has `repo` but not `workflow`, so any change to `.github/workflows/**` is refused at push time.
   - 11.2 sits built and committed locally. 11.5 and 11.6 also edit CI.
   - Pushing over SSH would get around the scope, so the Orchestrator didn't. It posted a blocked note asking Ely to run `gh auth refresh -h github.com -s workflow`.
3. **The land fix (#138) did its job on #158.** 10.3's round-2 P1 (R2-1) was confirmed and then fixed. Round 3 was clean, and land read `0 confirmed, 1 fixed`.
4. **The refuter earned its place on #158.**
   - R1-1 ("skipped rows are sent") was not reproduced: the email tool drops them itself.
   - The caveat, that a connector that doesn't re-check would send them, was fixed anyway, under the T3 rule on write safety.
   - R2-1 was confirmed with a "lying" connector that declares per-item keys and ignores them. The fix makes a retry send only the failed rows, under a derived key. A narrower same-day gap remains (#159).
5. **Builders sidestepped the write-path tripwire by rewording code (10.1, 10.2).**
   - Both times the code really was safe. But the precedent "reword until the check is quiet" is a bad one.
   - The architect caught it. 10.2 moved the `.write` reads into the allow-listed archetype instead.
6. **Plans with conditional approval worked.** The architect and plan reviews found 5 blockers in Epic 10's plan and 10 in Epic 11's. Each came with an exact edit, so they were folded in without waiting for Ely. One item needs Ely, but blocks no build: what template history a real client fork gets.

## Rule edits

- **AGENTS.md, Rules:** a change to `.github/workflows/**` needs a GitHub token with the `workflow` scope. If a push is refused for that reason, stop that story and post `--kind blocked`. Never push another way to get around the scope.
- **AGENTS.md, Rules:** never reword code just to quiet a check (write-path, job-imports, tier). If a check flags safe code, either move the code to where the check allows it or fix the check in its own reviewed change.
