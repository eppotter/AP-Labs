## The breach

- #164 and #165 fixed Epic 9 screens: a details view with no way back, and a modal fallback that showed nothing. Each story had shipped its main path with tests, but not every way out of its screens.
- These gaps would have shown in a live Slack check, and Epic 9 hasn't had one yet (it waits on Ely).
- **Rule edit:** a story that adds a Slack screen lists every way out of it in its acceptance criteria, with a test for each.

## What the numbers don't show

1. **The `workflow` scope worked as the last retro's rule intended.** The stack waited, unpushed, until Ely ran `gh auth refresh`. Then all four stories pushed normally.
2. **Two failures showed only in CI, and both were on steps no one could run locally.**
   - **11.2:** the smoke test required the MotherDuck extension to load with the network off. It can't: the extension asks MotherDuck's API for a version on every load. The check now proves the extension is installed and found offline. The plan records the changed acceptance criterion, and #169 tracks the remaining risk of a newer `motherduck_impl` in a read-only image.
   - **11.6:** a detached `git gc --auto` raced the fixture's own `git gc` in clean-bones. The fixture's git env now sets `gc.auto=0`.
   - **Rule edit:** steps only CI can run are named as untested in the report and the PR. If the check itself proves wrong, the changed acceptance criterion is written down and Ely is told.
3. **One review finding was wrong, and a one-line repro settled it.** On #171, the reviewer said `git switch -c main` fails after cloning at a tag. A scratch repo showed it works, and #172 was closed with that evidence.

4. **The full suite failed in the main checkout, never in CI or a worktree.** The fork fixtures copy tracked and untracked files, and `.claude/worktrees/` (the agents' nested checkouts) wasn't ignored, so 28 tests failed copying them. `.gitignore` now lists `.claude/worktrees/`.

## Rule edits

- **AGENTS.md, Rules:** a story that adds a Slack screen lists every way out of it (back, cancel, an error, an expired trigger) in its acceptance criteria, with a test for each.
- **AGENTS.md, Rules:** steps only CI can run are named as untested in the builder's report and the PR body. If the check itself proves wrong, the fix states the changed acceptance criterion in the plan and the PR, and Ely is told.
