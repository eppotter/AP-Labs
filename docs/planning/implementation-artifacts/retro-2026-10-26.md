## The breach

- **#177 is not a shipped defect.** It cleared ten filed review follow-ups in one PR. It counts as a fix by its Kind, but nothing it fixed had broken.
- **#176: a test fake accepted what the real API rejects.** Story 9.4's fake Anthropic client took any `tool_choice`. The real API returns 400 for a forced choice on Sonnet 5.5, Opus 5.5 and Fable 5.1, so "Read my request" always fell back to the form in Ely's live check. The fake now rejects a forced choice the same way.
  - **Rule edit:** a fake for an external API rejects what the real API rejects, for every request field the code sets.
- **#183: a test pinned one clock and not the other.** The approval-push tests pinned the store's clock at 2026-10-25, but the pull's run time came from the real clock. From 00:00 UTC on 2026-10-26, six tests failed on every branch, and the escalation test's leak check stopped checking anything while still passing. Both now freeze `Date` with node:test `mock.timers`.
  - **Rule edit:** a test that fixes the time fixes every clock the code reads.

## What the numbers don't show

1. **The `dist` CI job caught a real problem before its first run.** The builder's local `--check` failed one test inside the distribution copy: the fork guide's path check named `docs/reference/`, which never ships. That's the risk the job exists for.
2. **#181 used all three review rounds without a single blocking finding.** Two rounds came from the branch changing (Ely's deny-list edit, then the main merge after #183), not from the code.
3. **Plan item N7 was out of date.** 16 compressed seed files ship. The Orchestrator decompressed and scanned them (no hits), and #185 tracks scanning them automatically.
4. **A DEP row named in a plan was never added.** Plan epic-11 referred to a template-history DEP row, but the ledger never had it. #186 added it as DEP-019, closed.

## Rule edits

- **AGENTS.md, Rules:** a fake for an external API (Anthropic, Slack, the email tool) rejects what the real API rejects, for every request field the code sets. A test passing against a fake that accepts anything proves nothing about the real call.
- **AGENTS.md, Rules:** a test that fixes the time fixes every clock the code reads: freeze `Date` (node:test `mock.timers`) or pass `now` into every path, never only one store's clock.
