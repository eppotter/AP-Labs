| #239 | 2026-10-26 | 15.10 | user-visible | T3 (declared; computes T3) | The routing map now draws streets under the plot when the profile names a street-map source. The tiles go under the plot inside `png.js` as PNG data the kit writes itself from checked bytes (a 256 x 256 PNG of at most 256 KB, a whole grid covering the frame). The plot SVG still passes the unsafe-reference check before composing, and the composed SVG passes it again with the tiles taken out, so no path or web address ever reaches the rasterizer. A credit line linked to the provider's page sits right under the image; the alt text is unchanged. If the street layer can't be had (no tiles, the kill switch, a refused tile, a picture over the size cap, a failed draw), the plain map shows once more with "Street map unavailable, showing the plain map."; only a failed plain draw is the error exit. A newer click, Back or Close aborts the tile fetch; an expired session or withdrawn access after the fetch shows its message and uploads nothing. With no source the PNG is byte for byte what it was. The PNG cap is now measured: 510,077 bytes at most over dense synthetic street tiles, so the cap is 1,020,154 bytes. One log line per fetch gives tile counts and a reason code only. The smoke script also draws a view over fixture tiles and checks the no-network fallback; only CI runs it inside the image. | |
